# Personal Portfolio Website

A beautiful, modern, and fully responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Fully Responsive Design**: Works seamlessly on mobile, tablet, and desktop devices
- **Modern UI/UX**: Clean and professional design with smooth animations
- **Enhanced Visual Effects**:
  - Floating animation on hero image
  - Glassmorphism navbar with backdrop blur
  - Scale and lift hover effects on cards
  - Gradient buttons with smooth transitions
  - Animated skill progress bars
- **Interactive Elements**: 
  - Mobile hamburger menu
  - Smooth scrolling navigation
  - Form validation
  - Social media links with hover effects
- **Sections**:
  - Hero section with animated introduction
  - About Me section with contact info
  - Skills showcase with progress bars
  - Projects portfolio with 3 sample projects
  - Contact form with social links
  - Footer

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **JavaScript**: Interactive features and smooth animations
- **Font Awesome 6.4.0**: Beautiful icons
- **Google Fonts**: Poppins font family

## How to Use

1. **Open the website**: Simply open `index.html` in your web browser or use a local server
2. **Customize your information**:
   - Edit `index.html` to add your personal information
   - Update your name, skills, projects, and contact details
   - Replace placeholder content with your actual information
3. **Modify styles**: Edit `css/style.css` to customize colors, spacing, and effects
4. **Add functionality**: Customize `js/script.js` for additional features

## Customization Guide

### Update Personal Information

In `index.html`, replace:
- "Your Name" with your actual name
- "your.email@example.com" with your email
- "Your City, Country" with your location
- "+123 456 7890" with your phone number
- Social media links in the contact section

### Modify Colors

In `css/style.css`, search and replace the color values:
- Primary: `#6366f1` (Indigo)
- Secondary: `#8b5cf6` (Purple)
- Dark: `#1e293b` (Slate)
- Light: `#f8fafc` (Background)

### Add Your Projects

Replace the placeholder projects in the Projects section with your actual work, including:
- Project titles
- Descriptions
- Technologies used
- Live demo and GitHub links

### Add Your Photo

Replace the icon placeholders with your actual photos:
- Hero section image
- About section image
